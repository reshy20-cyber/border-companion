# رفيق الحدود · Border Companion

دليل قانوني للمسافرين والمقيمين: الفيزا وشروط الدخول والإقامة والقوانين المحلية وأرقام الطوارئ، في 28 دولة وبأربع لغات (العربية، English، Français، Deutsch).

- يعمل بدون إنترنت بعد أول فتح (sw.js).
- كل بيانات المستخدم تُحفظ في جهازه فقط.
- عند تعديل index.html: غيّر قيمة VERSION في sw.js حتى يصل التحديث للمستخدمين.
